# 群岛大亨资金流

每位玩家从 15,000 现金起步。现金可以立即付租或买地，存款要先取出，股票要先卖出。回合面板的「银行」「股票」和账单可以分别查看账户余额、持仓价值与实际收支。

## 收入、费用与排名

| 何时结算 | 金额与去向 |
| --- | --- |
| 经过起点 | 经过起点的玩家领取 2,000 航线收入。各人按自己的路线领款。 |
| 一整轮结束 | 每位仍在场的玩家各领 850 经营款，无论名下有几处地产。随后银行结息、股票更新报价。 |
| 停在集会或收费地块 | 集会发放 950 红利。收费地块金额随街区而异，落点时可在账单中查看。 |
| 停在机遇地块 | 可能收到 650 或 1,200，支付 650 维修费，或获得道具。 |
| 停在对手地产 | 访客将租金付给业主。已挂好的免租券可以抵消一次应付租金，双方都不会记入这笔收支。 |
| 到达约定轮数 | 结清最后一轮经营款、利息和行情后，在场玩家按净资产排名。仅剩一名玩家时提前结束。 |

**净资产 = 现金 ＋ 存款 ＋ 证券当期市值 ＋ 地产账面价值 － 未偿贷款。** 手牌不计价。净资产相同时先比手头现金，两项都相同则按座次决定。

## 买地、升级与收租

棋子沿道路行进，停在空置地产门前时可以按标价买入，也可以跳过。每处地产最高三级，普通升级费为地价的 55%，四舍五入至最接近的 50。每回合可以在掷骰前或行动结束阶段将一处名下地产升一级。街区工程队可以免费施工，也会用掉该回合的升级机会。

基础租金按地价的 18% 计算，一级、二级、三级分别乘以 1、1.85、3。持有同一街区的全部地产再乘 1.5，与卡牌效果合并后四舍五入到十位。地产账面价值等于原始地价加上当前等级对应的建造费用，免费升的等级同样计入价值。

在「玩法手册 → 买地与收租」里，从雾港群岛的 0 号启航码头走两步，经过 1 号灯芯作坊，停在 2 号晨雾渔市门前。花 2,200 买地，再花 1,200 升至二级。下一位访客停在门前，账单会显示他付给业主 730。若保持一级，租金是 400。没有额外加成时，每次收租多出 330，需要四次这样的停靠才能收回升级花掉的现金。用售价 700 的街区工程队升级，可以节省 500。[道具与租金效果](道具手册.md)

## 银行与证券

在自己的掷骰前、购买空地、逛商店、到访银行或行动结束阶段均可办理资金业务。经过岔口而尚有余步时，先选好去向再继续。金额和股数都须为正整数。

| 操作 | 结算方式 |
| --- | --- |
| 存入、取回 | 在现金和存款间等额转移。每轮末按存款余额的 1.2% 结息，利息向下取整，直接加入存款。 |
| 借款、还款 | 借款增加等额现金与欠款，还款同时减少两者。轮末按未还本金及已累计的利息计息 2.5%，向上取整，加入未偿贷款。 |
| 计算借款额度 | 基础额度 3,500，加上自己地产账面总值的 25%，向下取整到百位，最高 9,000。扣除已有欠款就是还能借的金额，最低为零。 |
| 放款手续费 | 在银行格借款免费。其他地块另付本金的 1%，向上取整。例如在外借 3,000，到手 2,970，增加 3,000 欠款。 |
| 买卖股票 | 按当轮统一报价买卖整股，双向零佣金。卖出时按加权平均持仓成本计算已实现盈亏，余下持仓随市价显示浮动盈亏。 |

每张图有两家银行。雾港群岛在 24、42 号，云轨山城在 26、51 号，赤沙商路在 26、68 号。停在银行时可以连续办理多笔业务，再结束回合。

三只股票的起始价分别为雾港航运 100、云轨机造 140、赤沙商贸 80。轮末统一更新价格，先取一次全市场的共同涨跌（幅度 3.3%），再分别取行业涨跌（幅度依次为 9.2%、7.6%、11.6%）。另加一项向初始价回归的修正 `0.074 ×（初始价 − 现价）/ 初始价`。将三项涨跌率相加后乘以现价，所得变动加回现价，四舍五入到整元。价格下限和上限分别是初始价的 39% 与 230%，取到整元。

## 缺款、变卖与破产

租金或费用超过现金时，付款暂停。你可以取款、卖出部分股票、在授信内借款，或指定出售某处地产。地产售出可回收账面价值的 65%，向下取整。筹足后立即按账单付款。

选择自动清算时，先取存款，再按股价从低到高卖出所需股份，最后从变卖价值最低的地产开始出售，筹足即停止。自动清算不会替你借款。资产用尽仍有缺口时，将实际筹到的现金交付，宣布破产并退出排名。

账单保留全桌最近 300 条明细，并按玩家、轮次和业务类别汇总最近三个有流水的轮次。存款利息、借款利息分别记入存款和负债，核对余额时可将它们与手头现金分开看。
