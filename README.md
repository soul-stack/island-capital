# 群岛大亨

一款在浏览器里玩的地产桌游，支持 **2–12 个席位**，真人和电脑可以同桌。你可以在云轨山城的岔口拦路，把对手引向自己的街区，也可以用测程罗盘算准步数，赶到银行免手续费借款。到约定轮数时，仍在场的玩家按净资产决胜。

[48 种道具和 6 组合成配方](docs/道具手册.md) · [银行、股票与资金结算](docs/资金流.md)

## 启动游戏

只有开服的电脑需要 Node.js。游戏服务支持 Node.js 22 及以上，本项目已用 Node.js 24 验证。前端、棋盘和 3D 渲染库都随仓库提供，无需安装 npm 依赖。

```sh
git clone https://github.com/soul-stack/island-capital.git
cd island-capital
npm start
```

打开 [本机游戏](http://localhost:3000)，就能在云轨山城和 3 位电脑玩家进行一局 30 轮的练习。Windows 也可以下载并解压仓库后双击 `启动游戏.cmd`。游戏期间保持服务窗口打开，按 Ctrl+C 关服。要换端口，运行 `node server.mjs --port 8080`。

## 第一回合怎么玩

1. **看路。** 每人带 15,000 现金，以及免租券、测程罗盘、岔口围栏、街区工程队各一张。点棋盘上的房屋或门前节点，可以看到业主、售价和租金。掷骰前可以出一张牌，比如用测程罗盘指定这次走几步。
2. **掷骰选路。** 通常掷两枚六面骰，沿箭头前进。还有步数时遇到多个可用出口，由你选择往哪里走。经过地产时可以继续前进，停在门前才触发买地或付租。
3. **经营地产。** 停在空地可以购买或跳过。掷骰前或结算后可以升级名下的一处地产，每回合限一次。最高三级，集齐同街区的地产，租金再提高 50%。要看一笔交易如何入账，可以打开「玩法手册 → 买地与收租」，跟着演示买下晨雾渔市，再从下一位访客手中收取 730 租金。
4. **结束回合。** 每位在场玩家各行动一次算一轮，完整轮末每人领 850 经营款。个人每经过一次起点，另领 2,000。仅剩一人时提前获胜。达到轮数上限时，按现金、存款、股票市值和地产账面价值之和减去贷款排名，同额时现金多者优先。

游戏共有 48 种道具。选卡时先预览目标和范围，确认后消耗。出牌和合成共用每回合一次的机会。商店出售常用卡，机遇和合成还能提供其他道具。[逐卡效果与合成方法](docs/道具手册.md)

## 和朋友联机

1. 主机运行游戏服务。同一 Wi-Fi 或局域网内，朋友用手机或电脑打开服务窗口打印的「局域网加入」地址。房主也用这个地址打开游戏，复制出的邀请链接就能直接分享。
2. 房主进入「联机大厅」，填写昵称，选择地图、人数上限和对局轮数。朋友可以打开邀请链接，或在大厅输入六位房间码加入。
3. 至少两席就座即可开局。房主可在候场室切换地图、添加电脑玩家，然后开始对局。每位玩家可独立切换 2D 或 3D 视角。

跨网络联机需要一台玩家均可访问的主机持续运行 Node 服务，并开放游戏端口。如果使用 HTTPS 反向代理，将整站连同 `/api/` 转发给同一个服务进程。Windows 首次开服时，若系统询问网络访问权限，允许 Node.js 在本次使用的专用网络上通信。

## 三张地图，两种视角

| 地图 | 地块 | 岔路 | 路线特色 |
| --- | ---: | ---: | --- |
| 云轨山城 | 71 | 3 | 默认练习地图。从山城总站出发，在内街、铁路和江港之间选路。 |
| 赤沙商路 | 86 | 4 | 路网最长。驼队营门、绿洲水道、香料集市与峡谷之间有多条分支。 |
| 雾港群岛 | 48 | 0 | 经典环线。适合先熟悉算步数、停靠买地和街区收租。 |

3D 沙盘支持拖动旋转、滚轮缩放，按住 Shift 拖动或右键拖动可平移。点「地标」看近景，点「全景」复位。2D 地图可以拖动平移、以光标为中心缩放，点「定位」找回当前棋子。触屏支持双指平移或缩放。两种视角共用同一份地契和棋子位置。

键盘聚焦棋盘后，3D 用左右方向键旋转，2D 用方向键平移、F 定位。两种视角都可以用加减号缩放、0 复位。想按街区查找地产，可打开「地块索引」。

## 公共地块与回合演示

停在商店可以购买道具，停在银行可以办理多笔业务。集会发放 950 红利，港务收费按街区计算。机遇地块可能带来现金、道具或维修账单。停航地块会耽误下一次行动，通行证可以放行。

游戏内「玩法手册」提供三个可操作的例子。在「控骰到银行」中练习存取款，在「岔路设障」中用围栏改变对手的路径，在「买地与收租」中看一笔租金如何记入双方账单。演示可以重玩，使用单独的棋局。

## 银行、股票与账单

存款每轮结息 1.2%，贷款每轮计息 2.5%。远程借款另收 1% 手续费，在银行门前办理可免收。航运、机造和商贸三只股票在同一轮内价格固定，轮末更新行情。

现金不足以付账时，可以取款、卖股、借款或出售指定地产。选择自动清算时，依次动用存款、股票和地产。变卖地产回收账面价值的 65%，资产用尽仍付不清才破产。回合面板的账单可以核对每笔收支。[资金流与估值规则](docs/资金流.md)

## 存档与重连

本地练习按地图保存在当前浏览器。用同一浏览器重新打开同一地址，就可以继续游玩。联机时，刷新原标签页会自动重连。关闭浏览器后，可以重新进入「联机大厅」，点击「恢复上次席位」。清除站点数据会清除席位凭据。

有其他真人在线时，玩家离线满 45 秒且轮到其行动，电脑会暂时代管。全体真人离线时对局暂停。主动离开进行中的对局会把席位永久交给电脑。

Node 服务把联机房间保存在 `.data/rooms/`。保留该目录即可在服务重启后继续对局。可用环境变量 `ROOM_DATA_DIR` 指定持久化位置，不同服务进程应使用各自的目录。
